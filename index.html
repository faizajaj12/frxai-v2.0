PANDUAN Cara Mendapatkan API Key Google AI Studio

  1. Buka situs resmi Google AI Studio di https://aistudio.google.com dan login menggunakan akun Google Anda.
  2. Klik menu "Get API key" lalu tekan tombol "Create API key".
  3. Salin (Copy) kode API Key yang muncul (biasanya diawali dengan AIzaSy...).
  4. Tempelkan API Key tersebut pada kolom di bawah ini, pilih model Gemini (otomatis atau ketik manual), lalu klik Simpan Konfigurasi.

Sistem otomatis memilih parameter terbaik untuk model ini.

Masukkan nama model resmi dari dokumentasi Google AI Studio.
